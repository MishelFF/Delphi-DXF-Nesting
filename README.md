# Delphi DXF Nesting demo
Демонстрационный проект на Delphi. Пытается прочитать полигоны (LWPOLYLINE) из DXF файла с моделью. Затем раскраивает полученные полигоны на листе. Размер листа задается в интерфейсе. Допускается поворот частей на углы, кратные 90 градусам. Можно выбрать алгоритм раскроя. Реализован механизм удобного добавления алгоритмов.
